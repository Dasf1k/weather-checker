Hi, I originally tried to make this project as a weather tracker, but due to a lack of skills and some issues, I was only able to implement this feature: you enter a city, and it tells you the country where that city is located. 
This is a small educational project I created to practice working with Python, GUIs, and APIs.
The project helps you learn about HTTP requests, JSON processing, and creating simple graphical applications.

Technologies Used:
Python
Tkinter
Requests
Open-Meteo API

Getting Started

Install the dependency:

pip install requests

Run the application
